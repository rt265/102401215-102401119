## Highlights

- 基于 Flutter 的跨平台统一体验
- 使用 Google Material Design，外观简洁
- 完善的搜索功能，可按名称、地点、分类、描述关键词搜索

## Installation

你可通过以下渠道获取安装文件：

| 版本 | 途径 | 说明 |
| -- | -- | -- |
| Release | [Github Releases](https://github.com/rt265/102401215-102401119/releases) | ⭐ 推荐的版本 |
| Latest | [Github Actions](https://github.com/rt265/102401215-102401119/actions/workflows/build.yml) / 自行构建 | 更快地接收最新变更 |

Release 版本文件说明：

| 文件                  | 类型               | 目标平台                           | 备注                      |
| --------------------- | ------------------ | ---------------------------------- | ---------------------     |
| `...arm64-v8a.apk`    | Android APK        | **64 位 ARM Android 设备**         | ⭐ 适用于绝大部分安卓设备 |
| `...armeabi-v7a.apk`  | Android APK        | **32 位 ARM Android 设备**         | 只适用于老安卓设备        |
| `...x86_64.apk`       | Android APK        | **64 位 Intel/AMD Android**，主要是模拟器等 | 很少使用         |
| `...ios-unsigned.zip` | iOS 安装包压缩文件 | iPhone / iPad                        | ⚠️ 用于 iOS 设备。未签名，不能像 APK 一样直接安装 |
