# 速拾失

一款简洁的跨平台校园失误招领移动应用，支持 Android 和 iOS。

目前只提供客户端的本地服务，以演示功能。

## Highlight

- 基于 Flutter 的跨平台统一体验
- 使用 Google Material Design，外观简洁

## Installation

可以从 [Releases](https://github.com/rt265/102401215-102401119/releases) 下载，或克隆仓库拉取代码后在本地构建。

| 文件                  | 类型               | 目标平台                           | 备注                      |
| --------------------- | ------------------ | ---------------------------------- | ---------------------     |
| `...arm64-v8a.apk`    | Android APK        | **64 位 ARM Android 设备**         | ⭐ 适用于绝大部分安卓设备 |
| `...armeabi-v7a.apk`  | Android APK        | **32 位 ARM Android 设备**         | 只适用于老安卓设备        |
| `...x86_64.apk`       | Android APK        | **64 位 Intel/AMD Android**，主要是模拟器等 | 很少使用         |
| `...ios-unsigned.zip` | iOS 安装包压缩文件 | iPhone / iPad                        | ⚠️ 用于 iOS 设备。未签名，不能像 APK 一样直接安装 |
| `...aab`              | Android App Bundle | Google Play / Android 发布         | ❌ 一般不能直接安装       |
