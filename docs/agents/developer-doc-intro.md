# 编写开发者文档

## 改动摘要

在 `docs/developer/intro.md` 创建了一份完整的开发者文档，覆盖以下内容：

1. **环境准备**：工具链版本、克隆与依赖安装、构建运行命令、目标平台。
2. **项目结构**：`lib/` 与 `test/` 的完整目录树与文件说明。
3. **架构概览**：分层（界面层/仓库层/模型层/基础设施）、数据流、启动序列。
4. **数据模型**：`ItemPost`、`UserAccount`、`PostQuery` 的字段表与枚举说明。
5. **数据存储**：SQLite 三张表（`posts`/`user_account`/`app_settings`）的列定义、仓储模式（Store + Repository）、状态下发（InheritedNotifier）、图片存储（文件名策略、迁移、清理、表单会话）、数据库迁移规范。
6. **界面层**：主界面外壳与 7 个页面的清单、关键设计（详情页按 id 现查、编辑页拦截返回、表单共用、联系方式自动带出、图片降级显示）。
7. **主题**：Material 3 配色、主题模式持久化。
8. **测试**：10 个测试文件的覆盖范围、测试策略（纯内存模式、SQLite 对拍、可测试性）、运行命令。
9. **编码规范**：Lint、Key 命名约定、文档注释要求。
10. **版本与发布**：版本号同步约定、发布产物、许可证。
